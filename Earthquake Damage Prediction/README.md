# Earthquake Damage Prediction

## Project Overview
This project focuses on predicting building damage caused by the Nepal Gorkha earthquake using Machine Learning.

## Objectives
- Perform Exploratory Data Analysis (EDA).
- Analyze building features and damage grades.
- Build Machine Learning models to predict building damage.
- Compare model performance and select the best model.
- Provide suggestions to reduce earthquake damage.

## Dataset
- train_values.csv
- train_labels.csv

## Tools and Technologies
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Project File
Earthquake_Damage_Prediction.ipynb

## Target Variable
damage_grade:
- 1: Low damage
- 2: Medium damage
- 3: Almost complete destruction
